# ToDoList

Учебное Android-приложение для управления списком задач, написанное на **Kotlin** с использованием **Jetpack Compose**.

## Возможности

- Добавление, редактирование и отметка выполнения задач.
- Назначение времени напоминаний с локальными уведомлениями.
- Локальное сохранение задач в `SharedPreferences` (JSON через Gson).

## Запуск

1. Откройте папку проекта в **Android Studio**.
2. Установите Android SDK 34 и подходящую версию JDK (обычно JDK 17+ для AGP 8.9.2).
3. Дождитесь синхронизации Gradle и запустите модуль `app` на Android-устройстве или эмуляторе с API 24+.
4. При необходимости разрешите приложению уведомления.

## Конфиденциальность

Реальные задачи пользователя **не включены в репозиторий**. Во время работы программа может сохранять задачи локально на устройстве.

## Примечание

Проект подготовлен к публикации: исключены локальные пути Android Studio, рабочие каталоги и файлы сборки. Полная сборка приложения в данной среде не проверялась.
